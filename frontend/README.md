# АвтоДеталь — фронтенд

Верстка онлайн-магазина автозапчастей (Nuxt 3 + Vue 3). Бэкенд подключается позже.

## Запуск

```bash
cd frontend
npm install
npm run dev
```

Сайт: http://localhost:3000

## Что сделано

- Шапка и подвал (layout)
- Модалки входа и регистрации
- Главная: баннеры функций, гараж, популярные товары, СТО-партнёры, товары по категориям
